## 五、需人工过一遍的流程清单

建议按顺序在打包版上走一遍，重点确认"修复后无副作用"：

1. 新建笔记 → 输入标题/正文 → 观察"已保存"状态自动出现
2. 正文加粗/斜体/标题/列表/折叠块/公式/表格/图片，各操作后格式面板高亮态正确
3. Ctrl+F 查找：输入关键词自动跳第一个、Enter 连续下一个、Esc 关闭；Ctrl+H 替换当前/全部
4. 视图切换：打字后立刻点"收藏"视图，内容不丢（bug #1 回归点）
5. 回收站：删除笔记 → 回收站中标题/替换不可用 → 恢复 → 永久删除（bug #2/#3 回归点）
6. 设置：切换深色模式后点取消，界面恢复浅色（bug #4 回归点）；保存后重启仍生效
7. 快捷键录制、历史版本恢复、备份/恢复、加密导出/导入
8. 隐私锁：设置 PIN → 隐藏窗口再呼出 → 输错/输对密码
